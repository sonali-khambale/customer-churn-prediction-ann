# 📊 Customer Churn Prediction using Deep Learning (ANN)

A Deep Learning project that predicts customer churn using an Artificial Neural Network (ANN).
The model analyzes customer data and predicts whether a customer is likely to leave the company.

---

## 📘 Overview

Customer churn prediction is an important business problem where companies try to identify customers who may stop using their services.
This project uses Deep Learning techniques and ANN models to improve prediction accuracy and automate churn analysis.

---

## 🚀 Features

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Encoding & Feature Scaling
* Artificial Neural Network (ANN)
* Model Training & Evaluation
* Churn Prediction System
* Accuracy

## 🧠 Deep Learning Model

The project uses a Sequential ANN model with:

* Input Layer
* Hidden Layers
* ReLU Activation Function
* Sigmoid Output Layer
* Adam Optimizer
